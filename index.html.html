A closer look at MediLens AI

REPORT_TREND.LOG 3 markers tracked

Lab reports, explained in plain English

MediLens AI extracts data from uploaded lab reports via OCR, then uses the Google Gemini API to explain each medical parameter in plain language — with a dashboard for report history, trend comparison, and flagging out-of-range values. Built with secure auth and storage through Supabase, and multilingual support across English, Telugu, and Hindi.
